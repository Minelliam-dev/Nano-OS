# Nano-OS
An operating system made for the arduino Nano

This project is made as a joke about
widows using gigabytes of RAM by making an 
entirely custom Operating system that uses less that 2kb of RAM

## It currently contains

- A window manager and task bar
- Custom windows with render calls and similar
- Simple Mouse inputs using an external joystick
- A siple task manager that drops fps by 200%
- A work in progress terminal


## Setup

- One stock Arduino nano
- A simple 120x160 TFT pixel screen
- A Sunfounder joystick
